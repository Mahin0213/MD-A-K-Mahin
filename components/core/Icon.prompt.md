Lucide glyph rendered as a currentColor mask — the only icon primitive in this system; never hand-draw SVG.

```jsx
<Icon name="arrow-up-right" size={18} strokeAlign="text" />
```

Any Lucide slug works. Sizes in use: 14 (inline meta), 18 (buttons), 20 (default), 28 (feature). Icons inherit color from the parent, so put color on the button/link, not the icon.
