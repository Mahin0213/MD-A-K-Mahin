The system's action primitive — mono, uppercase, letterspaced; never sentence-case.

```jsx
<Button variant="primary" size="lg" icon="arrow-up-right">Start a project</Button>
<Button variant="secondary">View my work</Button>
```

Pair exactly one primary with one secondary. Ghost is for tertiary/inline actions and has no horizontal padding. Press state scales to `--press-scale`; hover turns secondary/ghost lime.
